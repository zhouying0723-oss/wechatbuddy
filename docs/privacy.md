# 隐私说明

## 数据处理范围

WeChatBuddy 只在用户按下 `Command + Shift + R` 或主动点击改写命令时处理微信当前输入框中的草稿。应用不会读取聊天记录、联系人、已发送消息或其他会话内容。

为了生成改写结果，应用会把以下内容发送到用户配置的模型服务：

- 当前微信输入框中的草稿文字。
- 内置改写规则和用户选择的语气。
- 用户配置的模型 ID。

模型服务由用户自行选择和配置。模型供应商如何保存、使用或删除请求数据，受其服务条款和隐私政策约束，不由 WeChatBuddy 控制。

## 本机存储

- API Key 只保存在 macOS Keychain，不写入项目文件、UserDefaults 或应用日志。
- Base URL、模型 ID 和默认语气保存在 macOS UserDefaults。
- WeChatBuddy 不建立聊天内容数据库，也不持久化保存原始草稿或改写结果。

## 剪贴板与辅助功能

部分微信版本不向 macOS Accessibility API 暴露输入框文字。此时应用会临时使用系统剪贴板完成读取或写回，并在操作结束后恢复原剪贴板内容。

辅助功能权限仅用于确认微信状态以及读取和替换当前输入框草稿。应用不调用微信私有 API，不向微信进程注入代码。

## 消息发送

WeChatBuddy 只替换输入框草稿，不执行发送操作。用户必须检查改写结果并手动发送。

## 日志与问题排查

当前版本不记录 API Key、完整请求正文、原始草稿或改写结果。错误信息可能包含 HTTP 状态、模型供应商返回的错误说明和请求 ID，用于定位连接或配置问题；复制和分享错误信息前，用户仍应自行检查其中是否包含账号相关信息。
